# End-to-End Healthcare Data Warehouse on Snowflake

## About the Project

This project demonstrates the development of an end-to-end Healthcare Data Warehouse using **AWS S3** and **Snowflake**. The solution follows the **Medallion Architecture (Bronze → Silver → Gold)** to ingest, clean, transform, and organize healthcare data into analytics-ready datasets.

The project also includes audit logging, error logging, monitoring views, and a Snowsight dashboard to monitor pipeline execution and data quality.

---

## 🛠️ Tech Stack

* SQL
* Snowflake
* AWS S3
* Snowsight

---

## ✨ Key Features

* Built an end-to-end Healthcare Data Warehouse using the Medallion Architecture.
* Integrated AWS S3 with Snowflake using External Stages.
* Loaded raw healthcare data into the Bronze layer.
* Cleaned and transformed data in the Silver layer.
* Created analytics-ready datasets in the Gold layer.
* Implemented Audit Logging to track pipeline execution.
* Implemented Error Logging to monitor data quality issues.
* Created Monitoring Views for pipeline health monitoring.
* Built a Snowsight Operations Dashboard for pipeline monitoring.
